# PROJETON2
Projeto universitário da Disciplina Desenvolvimento Web. Um site sobre a Visibilidade de Pessoas com Deficiência (PCD)

Objetivo:
 A falta de visibilidade PCD em ambientes formais e o preconceito com essas pessoas é algo muito presente no dia a dia da população, com isso, criamos o PCDireitos com o objetivo de facilitar
 uso do site e levar a informação para as pessoas

Tema escolhido:
O tema escolhido pela equipe foi sobre pessoas com deficiência (PCD)
